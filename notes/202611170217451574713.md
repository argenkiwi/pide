In the Pi coding agent, prompt templates define custom slash commands (such as .pide/pi/prompts/containerfile.md). If a template does not include an argument placeholder such as $@ or $ARGUMENTS, Pi silently discards all arguments typed after the command during expansion. Appending $@ to the end of the template allows users to supply extra instructions or packages to /containerfile, while cleanly expanding to an empty string when the command is run without arguments.
