Apple's `container` is the third engine (after podman, docker); DetectRuntime picks the first engine that is installed AND running, so a stopped Docker does not block it. Verified on container 0.12.3: it rejects the SELinux `:z` volume suffix (mount fails with errno 22, data=z), so `container::volume_options` returns no suffix for it. It has no `--add-host`, so `host_args` emits nothing; the host is reached via `host.docker.internal`, which the user must create with `sudo container system dns create host.docker.internal --localhost 203.0.113.113`. If DNS resolves but connections time out, delete and re-create the name (the redirect, not DNS, was broken); the network gateway (192.168.64.1) is a fallback that worked. `image inspect` is JSON only; labels live at `variants[].config.config.Labels`, found by a recursive case-insensitive walk in `collect_label`.
