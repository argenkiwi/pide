ambler is a project template, not a library, so pide no longer depends on it. The only pieces pide used were the Node trait, Transition enum and Walk trait (with its default run loop); they were copied verbatim, with their tests, into src/engine.rs. Nodes and the pide walk import from crate::engine. ambler also brought in rand, which pide never used, so that dependency was dropped too. src/engine.rs is now pide-owned and free to diverge from the template.
